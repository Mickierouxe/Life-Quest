# Life Quest

A responsive, cozy-fantasy personal achievement dashboard built with React + TypeScript + Vite.

## Run locally
1. Install Node.js (LTS): https://nodejs.org/
2. Extract this project.
3. Open a terminal in the `life-quest` folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL printed by Vite (usually http://localhost:5173).

## Current working features
- Responsive desktop/mobile dashboard
- Active campaign with progress and milestone stamps
- One-tap movement session logging
- Quick Capture life-win journal
- Local browser persistence for campaign progress and wins
- Share latest win using the device share sheet (or clipboard fallback)
- Navigation placeholders for upcoming modules

## Notes
The sample campaign and collection counts are starter/demo content. Data is saved in the browser's local storage on the device/browser where you run it. Cloud sync and multi-user sharing are planned for a later phase.
